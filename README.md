# 線上四維堂｜政大百年攝影展

九〇年代日系像素風的線上展覽原型，為國立政治大學 2027 年百年校慶製作。

## 玩法

- 從四維堂前廣場走進展場，靠近照片按空白鍵或直接點擊，即可放大欣賞
- 入口的簽名簿可以簽名，左側的立式留言板可以貼便利貼
- 舞台布幕播放政大百年宣傳片
- 舞台兩側的郵筒可以寄明信片：綠色寄給未來的自己，紅色寄給 2027 年同樣逢整十週年的締約校
  - 線上明信片：內容印在明信片背面，寄到指定 Email
  - 實體明信片：邀請捐款支持四維堂風華再現計畫，由學校負擔郵資寄出

## 操作

| 動作 | 鍵盤 | 手機 |
|---|---|---|
| 移動 | 方向鍵或 WASD | 十字鍵，或點畫面 |
| 調查 | 空白鍵或 Enter | A 鍵 |
| 關閉 | Esc | B 鍵 |

## 目前狀態

這是原型版本：

- 展場內兩張為真實照片，其餘為像素示意圖，正式版換上授權的攝影作品
- 留言板、簽名簿與明信片紀錄目前存在各自的瀏覽器裡，正式版需要串接資料庫，大家才看得到彼此的留言
- 明信片不會真的寄出，正式版需要串接寄信服務

## 部署

純靜態網頁，單一 `index.html`，可直接放在 GitHub Pages 或任何網站主機。
